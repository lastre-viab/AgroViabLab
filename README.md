# AGROVIABLAB
AGROVIABLAB is an extension of the numerical library VIABLAB dedicated to the modelization and resolution of viability problems related to agro-economical systems.

It was developed by Anna DESILLES in collaboration with researchers of LC2S - UMR CNRS 8053 and  LASTRE.

This library is designed to be used for different research projects in the domain of viability theory applied to modeling and the analysis of agro-economical systems.
